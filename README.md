# Astral Client

Лаунчер для Minecraft Bedrock на Android: кнопка запуска, плавающая иконка поверх игры и меню с функциями.

## Что уже есть
- Лаунчер на весь экран (ландшафт) с проверкой разрешений
- Запуск Minecraft (`com.mojang.minecraftpe`)
- Плавающая иконка (перетаскивается), по нажатию открывается окно меню
- Иконка видна только пока Minecraft на экране; если игру закрыть, иконка пропадает, а сервис выключается сам
- Меню: поиск, список модулей в два столбца (переключатель + стрелка), справа настройки выбранного модуля (клавиша, HUD, масштаб, прозрачность), кнопка «Сброс». Всё сохраняется, окно двигается за шапку
- Сборка APK через GitHub Actions

Переключатели пока ничего не меняют в игре: это следующий этап.

## Как собрать APK через GitHub
1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. Открой вкладку **Actions**: сборка запускается при каждом push в `main` (или кнопкой *Run workflow*).
3. Скачай архив **AstralClient-debug** в разделе *Artifacts* и достань из него `.apk`.
4. Установи APK на телефон.

## Первый запуск на телефоне
В карточке «Подготовка» выдай два разрешения кнопками «Выдать»:
1. **Поверх других окон**: чтобы рисовать иконку и меню.
2. **Статистика использования**: чтобы приложение видело, что Minecraft закрыт, и убирало иконку.

Потом нажми «Запустить».
